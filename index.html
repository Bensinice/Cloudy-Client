Freunde
Freund hinzufügen und chatten. Spielt er gerade auf einem Server, steht ein ▶ neben seinem Namen: ein Klick, und du bist dabei. Schickst du einen Server-Code oder eine Adresse im Chat, erscheint dort ein „Verbinden“-Knopf. Alles läuft über dein Cloudy-Konto.

    

    
Noch nicht verbunden
Freunde hinzufügen und chatten geht, sobald du mit einem Freundesserver verbunden bist. Das dauert eine Minute.

    
Mit einem Freundesserver verbinden

      
So einfach geht’s: Einer klickt unten auf „Freundesserver hier starten“ und schickt den Code. Alle anderen fügen den Code hier ein und klicken „Konto erstellen“ – fertig, ab jetzt könnt ihr chatten.

      
      

      
Freundesserver selbst hosten
Startet den Server auf diesem PC (Port 7777, wird automatisch im Router freigegeben, wenn möglich). Gib Freunden nur deinen Freundescode – keine IP nötig.

Spiel

        
        
        
        
        
        
        
        
Vulkan braucht „Leistungs-Mods automatisch installieren“, Minecraft 1.17–1.21 mit Fabric und eine Vulkan-fähige Grafikkarte. Läuft es nicht, wieder auf OpenGL stellen.

        
        

      
Konten verwalten
Nur für Administratoren. Hier kannst du Konten pausieren, sperren (auch zeitlich), Items entfernen und Coins vergeben.

      
Codes erstellen
Ein Code gibt Coins und/oder Items. Jeder Spieler kann ihn einmal einlösen. „Einlösungen“ 0 = unbegrenzt viele Spieler.

        

        

      
Zugangscodes für den Launcher
Wer Cloudy neu installiert, muss beim ersten Start einen Zugangscode eingeben. Sobald du hier den ersten Code erstellst, funktioniert der alte feste Code nicht mehr (bereits freigeschaltete Installationen bleiben freigeschaltet). „Einlösungen“ 0 = unbegrenzt, „Tage“ 0 = läuft nie ab. Braucht den Konto-Server.

        

        

      
Konto-Server (nur Admin)
Optional: Trage die Adresse deines Cloudy-Servers ein, dann liegen alle Konten zentral dort und der Admin sieht alle Tester. Leer lassen = Konten nur auf diesem PC. Nach dem Speichern musst du dich neu anmelden.
